# ClothZone – E‑Commerce Clothing Store

Full‑stack e‑commerce website for clothing, built with **PHP, MySQL, HTML, CSS, JavaScript, Bootstrap**, and **Razorpay** payment integration.

🌐 **Live Demo:** [https://mahendradurgam.infinityfreeapp.com/](https://mahendradurgam.infinityfreeapp.com/)  
💻 **Source:** [MAHENDRADURGAM/clothzone-ecommerce](https://github.com/MAHENDRADURGAM/clothzone-ecommerce)

---

## Features

- **User System:** Registration, Login, Profile Management.
- **Shopping:** Product Catalog, Search, Cart, Wishlist.
- **Payments:** Razorpay Integration & Cash on Delivery (COD).
- **Admin Panel:** Manage Products, Orders, and Users.
- **Design:** Fully Responsive (Mobile & Desktop).

---

## Tech Stack

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Payments:** Razorpay

---

## Installation (Local Setup)

1. **Clone the repo:**
   ```bash
   git clone https://github.com/MAHENDRADURGAM/clothzone-ecommerce.git
   ```
2. **Database:** Create a DB named `clothzone` and import `install.sql`.
3. **Config:** Update `config.php` and `db.php` with your DB credentials.
4. **Run:** Start Apache/MySQL (XAMPP/WAMP) and open `http://localhost/clothzone-ecommerce`.
