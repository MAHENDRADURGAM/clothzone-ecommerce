# ClothZone E-Commerce Website

Full-stack e-commerce clothing website built with PHP, MySQL, HTML, CSS, and JavaScript.

## Features

* User Registration and Login
* Product Catalog Management
* Shopping Cart Functionality
* Order Management
* Admin Dashboard
* Product Search
* Responsive Design
* Razorpay Payment Integration

## Tech Stack

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap

## Installation

1. Clone the repository
2. Create a MySQL database
3. Import the provided SQL file
4. Configure `config.php` and `db.php`
5. Run the project using XAMPP, WAMP, or a PHP hosting provider

## Project Structure

* `admin/` - Admin panel
* `assets/` - CSS, JavaScript, and images
* `products/` - Product-related functionality
* `config.php` - Application configuration
* `db.php` - Database connection
