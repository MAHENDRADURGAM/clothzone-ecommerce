ClothZone - Final Deploy Instructions

1. Copy config.example.php to config.php and update DB + SMTP + Razorpay secret locally.
2. Import install.sql into MySQL.
3. Place razorpay secret in config/razorpay_keys.php as instructed.
4. Generate Gmail App Password and add to config.php for SMTP.
5. Ensure logs/ is writable.
6. Test on local XAMPP before live.
